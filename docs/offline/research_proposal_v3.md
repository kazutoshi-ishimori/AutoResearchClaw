## 2. 研究目的・方法など

### 2.1 本研究の学術的背景と核心的「問い」——生成過多時代における科学的労働の構造転換

#### 2.1.1 時代認識：生成コストの崩壊が「創造」を「検品」に変える

2024〜2026 年にかけて、生成 AI は「人間の創造的労働の輸入代替」から「人間の認知容量を超える供給過剰」のフェーズに入りつつある。象徴的な事例として、ローカル LLM 音楽生成モデル **ACE-Step** は、Suno クラス品質の 2 分楽曲を 1 分で生成する。単純計算で **1 日に約 1,440 曲**が産出可能であり、人間に残される創造的労働は「神曲を見つけ出す検品作業」に移行しつつある。

この構造転換はソフトウェア開発領域では既に現実のものとなっており（Copilot/Cursor/Claude Code 等による大量コード生成と人間によるレビュー・検品主体の作業フロー）、次に訪れる波は科学研究プロセスである。**仮説生成・実験設計・解析コード作成・論文執筆の各工程で LLM が人間の認知容量を超える候補を量産するようになったとき、科学者の仕事の中核は「生成」から「キュレーション（目利き・検品）」へと不可逆に移行する。**

#### 2.1.2 核心的ジレンマ：機微医学データだけがキュレーション革命から取り残される

しかし本構造転換には決定的な死角がある。**大規模医学コホートのように最も発見可能性に富む領域こそ、データの機微性ゆえに外部クラウド LLM を利用できない。** 東北メディカル・メガバンク機構（ToMMo）の三世代コホート（約 7.3 万人）・全ゲノム解析（約 1.5 万人）・多層オミックス・MRI 等は、閉域解析環境からの持ち出しが一切禁じられており、クラウド型 LLM 協働研究の恩恵を受けられない。

この結果、

- 生成 AI を自由に使える「一般的な研究領域」では、仮説・解析・論文生成がコモディティ化し、2028 年頃には閉域外の研究労働は「キュレーション主体」に移行する
- 一方、医学的・社会的に最も重要な機微データ研究領域は、**従来型の人手研究プロセスに取り残される**
- **発見支援 AI の恩恵を最も必要とする領域が、それを受けられないという構造的ジレンマ**が深刻化する

#### 2.1.3 核心的な学術的問い

以上の時代認識と構造的ジレンマから、本研究は以下の三位一体の問いを立てる：

> **Q1（パラダイム論）**: 生成コストが極小化した時代において、「キュレーション駆動型科学発見」はどのような労働構造・評価規範・信頼性保証機構を持ちうるか。
>
> **Q2（制約駆動論）**: 機微データという絶対的な持ち出し禁止制約と、倫理的観点から要請される人間専門家の介在という境界条件は、クラウド LLM では到達不可能な**深いドメイン特化型推論**を創発させうるか。
>
> **Q3（協働論）**: AI が自身の推論不確実性を自覚し、人間専門家に対して「次にどのデータを追加すべきか」を逆質問する **Active Inquiry 型 HITL** は、単なる承認ゲートを超える学術的協働モデルとして成立するか。

#### 2.1.4 本研究が採る立場：「制約駆動型科学的推論基盤」としての再定義

本研究は「クラウド LLM が使えないから閉域で頑張る」という**守りの論理を退ける**。むしろ、機微データという絶対的制約と倫理的 HITL 境界条件を、**閉域内で深い推論を創発させる設計的資源**として積極的に活用する。これを **制約駆動型科学的推論（Constraint-Driven Scientific Reasoning）** と呼び、本研究の中心概念に据える。

#### 2.2.2 学術的独自性・創造性

**独自性 1：世界初のキュレーション駆動型科学発見の実証**
楽曲・コード領域では既に現実化しつつある「生成過多 × 人間キュレーション」構造を、**科学研究プロセス全体**に対して、**機微データ閉域環境**という厳しい境界条件下で初めて実証する。これは日本の大規模コホート資産を用いてしか実施不可能な研究であり、国際的に代替困難な学術的ポジショニングを実現する。

**独自性 2：Active Inquiry 型 HITL の学理化**
従来の HITL 研究は「人間による承認ゲート（Approve/Reject）」を中心としたが、本研究は**AI 側からの能動的逆質問**——推論不確実性を検知した AI が「この仮説を絞り込むために、どの表現型データを追加すべきか」「どの族内比較を行うべきか」を人間に問いかけ、人間の応答を次の仮説空間探索に反映する——という双方向協働の設計論を体系化する。単なる「一時停止ボタン付き自動化」との本質的差異を明確化する。

**独自性 3：制約駆動型推論の実証**
「外部通信ゼロ」「PHI 持ち出しゼロ」「人間介入必須ゲート」という複合制約を、**推論の質を劣化させる障害としてではなく、深いドメイン特化を強制する設計的資源として活用する**アプローチを、理論・実装・評価の三面から検証する。

**独自性 4：二層到達目標によるリスク堅牢性**
「既知知見の再発見」を安全側マイルストーンとして配置しつつ、「未報告サブ仮説の提示」を挑戦側ゴールとして並行追求する構造により、発見の不確実性を完全にはヘッジしつつ Wow ファクターを失わない計画設計を実現する（科研費大型枠の「手堅さ」と「野心」の両立）。

**独自性 5：日本人コホート特異性の学術価値**
ToMMo データは世界最大級の三世代東アジア系コホートであり、欧米中心の既存研究では見えない**集団特異的な遺伝・環境・疾患連関**の発見余地を持つ。これは単なる応用ではなく、国際的な未探索領域を拓く学術的意義を持つ。

### 2.3 本研究で何をどこまで明らかにするか

1. **キュレーション駆動型科学発見パラダイム**の理論的・実証的輪郭：労働構造、時間配分、信頼性保証機構、人間専門家の認知負荷と満足度、既存の「仮説駆動型」「データ駆動型」パラダイムとの比較
2. **Active Inquiry 型 HITL プロトコル**の設計原理・実装技術・有効性：逆質問生成の不確実性基準、人間応答の仮説空間への反映機構、従来型承認ゲート HITL との比較評価
3. **閉域制約下での推論品質保証機構**：外部通信ゼロの技術的保証、PHI 保全マスカー、ハッシュチェーン監査ログ、人間承認を要する決定の体系的分類
4. **二層到達目標の達成度**：(a) ToMMo 既知論文の知見再発見の成功率と所要時間、(b) AI が提示する未報告サブ仮説の新規性と医学的妥当性（独立専門家評価）
5. **従来型研究プロセスとの比較定量データ**：同一研究課題に対する人手研究・本基盤・クラウド LLM 補助（比較対照）の三条件比較（仮説生成網羅性、発見スループット、最終成果の質）

## 4. 着想経緯

### 4.1 個人的観察：ACE-Step ショックと労働構造転換への直観

研究代表者は、ローカル音楽生成 LLM ACE-Step（2025 年公開）が Suno 商用品質の 2 分楽曲を 1 分で生成する事実に接し、「1 日 1,440 曲の生成能力があれば、1 曲は神曲が混ざる。それを見つけ出すのが人間の仕事になる。クリエィティブな仕事が工場の検品作業の様になる」という直観を得た。コーディング領域ではこの転換は既に現実化しており、次に訪れる波は科学研究プロセスであろうと予測した。

### 4.2 実践的観察：AutoResearchClaw の運用経験

研究代表者は、2025〜2026 年にかけて 23 ステージ自律研究パイプライン AutoResearchClaw（OSS、Apache-2.0）を開発・運用し、LLM が仮説生成・実験設計・論文執筆の全工程を遂行できることを実証した。同時に、ユーザー大学での適用を検討する過程で、**機微データ領域だけがクラウド LLM の恩恵を受けられない**という構造的ジレンマに直面した。

### 4.3 統合：制約駆動型キュレーション発見という着想

上記の時代観察と実装経験を統合し、「機微データの閉域制約はハンディキャップではなく、むしろ**キュレーション駆動型科学発見パラダイム**を実証する唯一かつ最適なラボラトリである」との着想に至った。日本の大規模コホート資産（ToMMo）の存在がこの実証を可能にする国際的希少条件であることから、本研究を挑戦的研究（開拓）として申請する。

### 5.2 技術的要素（抜粋）

**基盤（`docs/offline/requirements.md` 準拠）**
- 閉域 LLM: Qwen 3.5-35B-A3B（プライマリ） / Gemma 4 26B-A4B（レビュー・判定） / Gemma 4 31B（コード生成）——全て Apache-2.0
- ランタイム: Ollama / vLLM（VRAM 24–48GB 想定、プロファイル A/B）
- 埋め込み: `intfloat/multilingual-e5-large`（ローカル推論）
- 文献コーパス: DMZ 事前取得 PDF + BM25＋ベクトル検索ハイブリッド

**Active Inquiry エンジン（新規開発）**
- 不確実性検出: トークン対数尤度分散、複数サンプリング間の意見不一致率、知識ベース参照失敗率の 3 軸
- 逆質問テンプレート: 「仮説絞込」「追加データ要求」「手法選択相談」「結果解釈確認」の 4 類型
- 応答反映: 人間応答を次ラウンドのプロンプトコンテキストに構造化統合

**制約駆動型推論の保証機構**
- 外向き通信: nftables でプロセス単位に遮断、ログを監査対象化
- PHI マスカー: 正規表現 + 辞書 + 文脈埋め込み距離の三段フィルタ、合成データで F1 評価
- 監査ログ: 各意思決定に前レコードのハッシュを記録、改竄検出可能

### 5.3 評価設計

#### 5.3.1 技術基盤評価（T1–T5）

専用の合成機微データセット（ToMMo 構造を模した fake cohort）で T1–T5 を測定。T1・T2・T3 は定量的に合否判定。

#### 5.3.2 科学実証評価（S1–S4）

**再発見評価（S2）**: ToMMo 既存論文 5 本を選定、該当論文が用いた生データ範囲を閉域内で AI に与え、論文閲覧禁止条件で主要結論を導出可能か検証。独立評価者 3 名が盲検で「主要結論一致度」を 5 段階評価。

**新規性評価（S3）**: 再発見プロセスで派生する副次仮説を収集、独立医学専門家 3 名が (a) 既存文献照合、(b) 医学的妥当性評価、(c) 検証可能性評価を盲検実施。Fleiss κ で評価者間一致度を確認。

#### 5.3.3 パラダイム論評価（P1–P4）

**Active Inquiry 有効性（P1）**: 同一研究課題に対し「承認ゲートのみ HITL」vs「Active Inquiry HITL」の A/B 比較。仮説収束速度、最終成果質、人間専門家の認知負荷（NASA-TLX）を測定。

**キュレーション労働ログ（P2）**: 全フェーズの人間専門家操作を時系列ログ化、匿名化後に公開。「判断所要時間分布」「AI 提案への同意率」「見逃し仮説の後付け検証率」等を分析。

### 5.4 ベースライン比較

| 条件 | 説明 | 比較軸 |
|------|------|--------|
| B1: 人手のみ | 従来型研究（共同研究者 1 名が通常の解析を行う） | S1, S2, S3, P1 |
| B2: クラウド LLM 補助（開放データ） | 匿名化された開放データに対する GPT-5.4 補助研究 | 発見スループット |
| B3: 閉域承認ゲート HITL のみ | 本基盤から Active Inquiry を除外 | P1 |
| B4: 本基盤フル構成 | 閉域 + Active Inquiry | 全軸 |

## 6. 研究体制

（共同研究者の具体名は大沼先生との調整後に確定。以下は役割の枠組み）

- **研究代表者（PI）**: 情報系。AutoResearchClaw 開発・運用、閉域基盤設計、Active Inquiry エンジン実装
- **分担者 A（医学・遺伝統計）**: ToMMo 関連または同等コホート研究経験者。科学実証層の評価、既知知見再発見の検証
- **分担者 B（研究倫理・HCI）**: 機微データ研究倫理、HITL 設計、キュレーション労働評価
- **協力機関**: ToMMo（データ提供・利用環境）、国内大規模計算基盤（所属大学 HPC）
- **研究協力者**: 独立評価パネル 3 名（外部医学研究者、盲検評価担当）

- 情報系・医学系の学生・若手研究者が「閉域制約下での AI 協働研究」という新領域で研鑽を積む機会を創出

## 11. リスクと対策

| リスク | 影響 | 対策 |
|-------|------|------|
| ToMMo データ利用承認が遅延または不可 | 重大 | 早期申請、同等の他コホート（BBJ 等）を代替候補として並行準備 |
| 閉域環境での LLM 利用が所属機関ポリシー上制限される | 重大 | P0 で許諾確認を Blocker として明示、代替として synthetic cohort のみでの評価も可能な設計 |
| 未報告サブ仮説が 3 件得られない（S3 未達） | 中 | 既知再発見（S2）と Active Inquiry 評価（P1）で定量成果は確保、S3 は「挑戦的成果」として位置付け |
| Active Inquiry の逆質問品質が不十分 | 中 | 複数の不確実性検出指標を並行実装、人間応答の構造化により学習改善を反復 |
| 2028 年までに閉域 LLM 論文生成がコモディティ化 | 低〜中 | 本研究の価値は「キュレーション労働の学理」にあり、モデル性能向上は追い風であって脅威ではない |
| 独立評価者のバイアス・不一致 | 中 | 3 名体制、Fleiss κ による一致度検証、評価ルーブリック事前公開 |

## 12. 挑戦的研究（開拓）への適合性

挑戦的研究（開拓）は「独自発想、遂行方法、研究期間等によって従来の学術的パラダイム・研究領域の変革や新領域の開拓を志向する研究」を対象とする。本研究は：

1. **既成パラダイムへの挑戦**: 「仮説駆動型」「データ駆動型」に続く第三の「キュレーション駆動型」パラダイムを提唱
2. **新領域開拓**: 機微データ × 生成 AI × 人間キュレーションという国内外未開拓の交差領域
3. **独自発想**: ACE-Step に象徴される生成過多時代の労働構造転換を、医学研究領域において閉域制約下で先行実証する発想は国際的にも先駆的
4. **失敗を織り込んだ挑戦設計**: 既知再発見を安全側マイルストーン、未報告サブ仮説提示を挑戦側ゴールとする二層設計により、「失敗許容の野心」を具体化
5. **日本の固有資産活用**: ToMMo という世界最大級の東アジア系コホート資産を活用、国際代替困難な学術的ポジション
