## 1. 研究課題名

**機微医学データを対象とする自律的研究プロセスの閉域実装——大規模言語モデルを用いた仮説形成・実験実装・論文執筆の end-to-end 自動化**

（英文）*Closed-Network Autonomous Research Pipeline for Sensitive Biomedical Data: End-to-End Automation of Hypothesis Formation, Experiment Execution, and Manuscript Generation via Large Language Models*

## 2. 研究目的・方法など

### 2.1 本研究の学術的背景と核心的「問い」

大規模言語モデル（LLM）を中核とする自律研究エージェント——文献探索・仮説生成・実験コード生成・結果解釈・論文執筆を連結し実行するパイプライン——は、2024〜2026 年にかけて急速に実用段階へ移行した。AI Scientist（Sakana AI, 2024）、AutoResearchClaw（aiming-lab, 2025）、A-Evolve（2025）などの登場により、「研究プロセスそのものの自動化」は研究方法論上の新たな独立したパラダイムとなりつつある。

しかし、**これら既存システムはいずれも外部クラウド API（OpenAI, Anthropic, Google 等）への依存を前提**としており、個人情報保護法・改正個人情報保護法・各種データ利用規程の下で**機微な医学研究データには一切適用できない**という構造的制約を抱えている。特に全ゲノム解析データや大規模コホートの臨床情報は、それ自体が個人を再識別しうる情報として扱われ、東北メディカル・メガバンク機構（ToMMo）をはじめとする国内外の大規模バイオバンクは、分譲先の閉域解析環境からのデータ持ち出しを厳格に禁じている。結果として、**研究自動化という最先端の方法論が、その恩恵を最も必要とする大規模医学研究データに届かない**という深刻な技術的・社会的ギャップが存在している。

本研究の核心的な学術的問いは以下である：

> **「自律研究エージェントを、外部通信ゼロ・個人情報残留ゼロの閉域環境下でいかに構築すれば、実データに対する科学研究プロセスを安全かつ再現可能に自動化できるか」**

この問いは、単なる工学的実装の問題ではなく、**AI 駆動型研究の適用可能範囲を「公開データ領域」から「機微データ領域」へと拡張するための方法論的基盤**を問うものであり、AI for Science 分野における未踏の課題である。

### 2.2 本研究の目的と学術的独自性・創造性

本研究の目的は次の三点である。

**目的 1（基盤構築）**
外部通信を一切行わずに、仮説形成・文献調査・実験コード生成・実行・統計解析・論文執筆の全工程を完遂する**閉域型自律研究パイプライン**を構築する。Apache 2.0 ライセンスの OSS `AutoResearchClaw` (v0.4.0) を基盤とし、ローカル LLM（Qwen 3.5, Gemma 4）、ローカル埋め込みモデル、ローカル文献コーパスによる全置換を行う。

**目的 2（機微データ保全機構）**
個人識別情報（PHI）がプロンプト・ログ・キャッシュ・成果物のいずれにも残留しないことを、**検証可能な形で保証する機構**を設計する。すなわち、(a) PHI マスカーによる事前除去、(b) hash chain に基づく改竄検出可能な監査ログ、(c) 多段 Human-in-the-Loop（HITL）ゲートによる段階的承認、の三層で保証する。

**目的 3（実証と方法論確立）**
ToMMo の dbTMM 実データに対して本システムを適用し、**研究プロセス自動化の品質・再現性・安全性を多角的に評価**する。これにより、機微データを対象とする自律研究 AI の運用方法論を学術的に確立する。

**学術的独自性・創造性**：
- **第一**に、「自律研究エージェント」と「閉域医学データ運用」という、従来交わらなかった二領域を橋渡しする国内外初の体系的試みである。
- **第二**に、LLM を含む研究プロセス全体に対して**外部通信ゼロを設計原理として保証**するアプローチは、既存の "差分プライバシー"・"連合学習" 等の部分的プライバシー保全手法とは本質的に異なる、新規のアプローチである。
- **第三**に、監査可能性と説明責任を備えた AI 駆動研究基盤は、研究公正（Research Integrity）と AI 倫理の接点における新たな学術的知見を提供する。

### 2.3 本研究で何をどこまで明らかにするか

本研究は 24 ヶ月で以下を達成する。

| 段階 | 達成目標 |
|---|---|
| 基盤実装 | 外向き通信ゼロを `nftables` レベルで検証可能な閉域パイプラインの完成 |
| PHI 保全機構 | マスカーの再現率・適合率をアノテート済評価セットで定量評価（目標 F1 ≥ 0.95）|
| 文献基盤 | 学外 DMZ 構築コーパス（≥10 万論文）のローカル検索基盤の整備 |
| 実証 (1) | 公開データ（1000 Genomes 等）による end-to-end 論文生成の再現性検証 |
| 実証 (2) | ToMMo 実データを用いた自律生成論文 2〜3 本を査読付き国際誌へ投稿 |
| 方法論 | 閉域自律研究パイプラインの設計原則と評価フレームワークを方法論論文として発表 |

### 2.4 着想に至った経緯と国内外研究動向

**着想の経緯**：
研究代表者は過去 1 年間にわたり AutoResearchClaw を用いた公開データ領域での論文生成を実運用し、その有用性と限界を実地で検証してきた。この過程で、「ToMMo 等の機微データに同様の方法論を適用できないか」という実務課題に直面し、既存システムがクラウド前提であるがゆえに本質的に適用不可能であることを確認した。この構造的課題を克服する新たな研究基盤の構築こそ、日本の医学研究 DX にとって最優先の課題であるとの認識に至った。

**国内外研究動向**：
- **自律研究エージェント**：Sakana AI の AI Scientist（2024）、aiming-lab の AutoResearchClaw（2025）、A-Evolve（2025）など、オープンソース系の台頭により、方法論が急速に成熟している。
- **ローカル LLM**：Qwen 3.5（Alibaba, 2026）、Gemma 4（Google, 2026）の登場により、Apache 2.0 ライセンスかつ閉域運用可能な大規模モデルが初めて現実的な選択肢となった。
- **機微医学データと AI**：連合学習・差分プライバシーが主流だが、これらは統計モデリングに閉じており、**研究プロセス全体の自動化には適用できない**。
- **本研究の位置づけ**：上記三潮流の交点に位置し、**「機微データ領域における研究プロセス自動化」という新領域を開拓する**ものである。

## 3. 研究方法

### 3.1 全体設計

既存 OSS `AutoResearchClaw` v0.4.0 を基盤に、9 フェーズで閉域対応を実装する。詳細は `requirements.md`（別紙）を参照。

| フェーズ | 内容 | 期間 |
|---|---|---|
| Phase 0 | 要件確定・規程確認・環境調査 | 0.5 ヶ月 |
| Phase 1 | `offline_mode` フラグと外部通信遮断機構 | 0.5 ヶ月 |
| Phase 2 | ローカル LLM バックエンド統合 | 0.5 ヶ月 |
| Phase 3 | ローカル埋め込み・ベクタ検索 | 1 ヶ月 |
| Phase 4 | ローカル文献コーパス基盤 | 2 ヶ月 |
| Phase 5 | ゲノム解析対応実験実行環境 | 2 ヶ月 |
| Phase 6 | ドメイン特化スキル（WGS・ToMMo コホート） | 1 ヶ月 |
| Phase 7 | HITL ゲート・監査ログ強化 | 1 ヶ月 |
| Phase 8 | 公開データによる E2E 検証 | 1 ヶ月 |
| 実証 | ToMMo 実データによる論文生成実証（2〜3 テーマ） | 6 ヶ月 |

### 3.2 評価設計（自動化性能の定量評価）

類型 5（実験自動化・自律化）に対応する本研究では、**自動化そのものの性能**を以下の 6 軸で定量的に評価する。

| 評価軸 | 指標 | 目標値 |
|---|---|---|
| **自動化完遂率** | ステージ単位の完遂率（全 23 ステージ中の達成数 / 総数）| ≥ 0.90 |
| **研究者工数削減率** | 自動生成 vs 人手執筆の工数比 | ≥ 70% 削減 |
| **セキュリティ** | 外向き通信回数（nftables 計測）| 0 |
| **PHI 保全** | マスカー F1（アノテート済評価セット）| ≥ 0.95 |
| **再現性** | 同一入力・同一シードでの出力類似度（BERTScore 等）| ≥ 0.85 |
| **成果物品質** | 分野専門家によるルーブリック評価（5 段階 × 6 軸）| 中央値 ≥ 4.0 |

この 6 軸評価は、**自律研究システムに対する評価フレームワーク**そのものを方法論論文として打ち出す材料ともなる。

### 3.3 ベースラインとの比較

以下 3 条件との比較実験を行い、本システムの優位性を検証する。

- **ベースライン A**：完全人手による従来の研究プロセス
- **ベースライン B**：クラウド LLM 利用可能な公開データでの AutoResearchClaw 原版
- **本システム**：閉域・ローカル LLM 版

## 5. 期待される成果

### 5.1 学術的成果
- **方法論論文**：「閉域自律研究パイプラインの設計原則」（情報学系・医学情報学系ジャーナル、1〜2 本）
- **実証論文**：ToMMo 実データを用いた研究成果論文（本システム自身で生成、2〜3 本、国際誌）
- **評価フレームワーク論文**：自律研究システム評価の 6 軸ベンチマーク（1 本）

### 5.2 社会的・実用的成果
- **OSS 公開**：本システムを Apache 2.0 で公開し、国内外のバイオバンク・研究機関による再利用を促進
- **人材育成**：大学院生・若手研究者への「AI 駆動研究」トレーニング基盤として活用
- **政策的貢献**：データ主権・国産 AI 研究基盤整備の観点から、政策議論への材料提供

### 5.3 研究 DX への波及
機微データを扱う領域（医学、ゲノム、心理、教育等）全般に波及可能な汎用基盤として、国内外の同種課題を抱える研究機関に対し、追跡可能な実装参照を提供する。

## 6. 倫理的配慮と法令遵守

- ToMMo データ利用は既存の分譲契約および各機関の IRB 承認の範囲内で実施する。
- 本研究の主題自体（LLM の医学研究利用）が新規性を持つため、本システムの利用そのものに関する**追加 IRB 申請**を実施する。
- 生成された論文・仮説の公表前には、**分野専門家による人手レビューを必須**とし、ハルシネーションによる誤った医学的主張が外部に出ない運用とする。
- 全 LLM 入出力の監査ログを hash chain 付きで **10 年間保管**し、事後追跡可能性を担保する。
- 個人情報保護法および改正個人情報保護法、人を対象とする生命科学・医学系研究倫理指針、ヘルシンキ宣言を遵守する。

## 9. リスクと対応方針

| リスク | 影響 | 対応 |
|---|---|---|
| 規程上 LLM 利用不可 | プロジェクト成立不可 | Phase 0 で文書確認。不可の場合は公開模擬データで方法論のみ確立する計画 B に切替 |
| ローカル LLM 品質不足 | 論文品質低下 | Qwen 3.5 / Gemma 4 の比較選定済。プロファイル A（上位 GPU）へ拡張予算を確保 |
| 倫理審査長期化 | スケジュール遅延 | IRB 申請を Phase 0 と並行開始 |
| Upstream との衝突 | 保守負荷増 | アダプタ/プラグイン形式で実装し、本体ファイル改変を最小化 |
| PHI マスカー漏れ | 重大インシデント | 正規表現＋語彙＋単体テスト＋ランダムサンプル人手レビューの多層防御 |
